# Projeto de Otimização do Acompanhamento Gestacional

Desenvolvimento de uma planilha automatizada em Google Planilhas para auxiliar no acompanhamento gestacional e organização operacional.

## Funcionalidades
- cálculo automático de idade gestacional
- dashboards automatizados
- filtros automáticos
- categorização por equipes
- acompanhamento operacional

## Tecnologias utilizadas
- Google Planilhas
- Dashboards
- Automação de Dados

## Objetivo
Facilitar a visualização e acompanhamento das gestantes através de automações e indicadores visuais.
